Desktop app

The desktop app is the web UI packaged with Tauri 2. It works offline: business services run in the window against a local SQLite database (sql.js in WebAssembly).

Install a release

Installers are attached to each tagged version, and the download page picks the right one for your platform. They are not code-signed yet, so your OS warns you on first launch:

  • Windows: SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.
  • macOS: Gatekeeper refuses to open the app. Right-click (or Control-click) the app, choose Open, then confirm. If it still says the app is damaged, run xattr -dr com.apple.quarantine /Applications/centime.app.
  • Linux: no warning. For an AppImage, make it executable first: chmod +x centime_*.AppImage.

Updates

Settings › Updates shows the installed version and compares it with the latest release on GitHub. The check runs when the page opens, at most once an hour, and on demand. It only reads the public release manifest.

  • Desktop: the app downloads the signed package, installs it and restarts.
  • Android: the card downloads the .apk of the release, which Android installs over the current app.
  • Web: the card links to the release, since the version served is the one deployed on your server.

An update only installs if it is signed with the project key, so a package from anywhere else is refused.

Build it

Requirements: stable Rust, and the Tauri system dependencies (WebView2 on Windows, Xcode Command Line Tools on macOS, WebKitGTK 4.1 on Linux).

bun run desktop:dev     # development window
bun run desktop:build   # installer

The installer lands in apps/desktop/src-tauri/target/release/bundle.

Local database

Each account has its own folder accounts/<id>/ in the application data folder, with its database centime.db and its key master.key. The file accounts.json lists the accounts and the active one. The application data folder is:

  • Linux: ~/.local/share/ch.centime.desktop/
  • macOS: ~/Library/Application Support/ch.centime.desktop/
  • Windows: %APPDATA%\ch.centime.desktop\

Several accounts can coexist on one device: Settings › Accounts adds, renames and switches them. Files from an earlier single-account version are moved into accounts/<id>/ automatically.

Each database is saved 500 ms after each change and when the window closes, and the file is encrypted with AES-256-GCM. Its master key is stored next to it, so disk encryption (BitLocker, FileVault…) is still advisable.

Connect synchronization

  1. On first launch, create a key or enter an existing one.
  2. Enter the server address on that screen, or later in Settings › Synchronization.
  3. The app derives its credentials from the key and runs a first sync.
