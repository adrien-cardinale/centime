Self-hosting

The server is a small Hono API on Bun that stores encrypted blobs in SQLite and serves the web build. It holds no business data and no business logic.

Docker Compose

git clone https://github.com/adrien-cardinale/centime.git
cd centime
docker compose up -d

This builds the image, listens on port 3000 and keeps the database in the centime-data volume.

Without Docker

bun install
bun run build
bun run start

The server has no build step: Bun runs the TypeScript directly.

Configuration

VariableDefaultPurpose
PORT3000HTTP port
DATABASE_PATH./data/relay.dbRelay SQLite file
ALLOW_SIGNUPtrueWhether unknown user ids can create an account. Set to false once you have created yours.
STATIC_DIRemptyOverride for the web build folder
MAX_USER_BYTES536870912Storage quota per user id in bytes, log and files together (512 MiB). 0 disables the quota.
RATE_LIMIT_PER_MINUTE300Maximum API requests per minute and per client. 0 disables the limit.
ALLOWED_ORIGINSemptyComma-separated origins of a web app hosted elsewhere (for example https://you.github.io) allowed to reach the relay. Leave empty when the relay serves the web app itself.

HTTPS

Web Crypto needs a secure context, so serve the browser version over HTTPS, or from localhost. Put a reverse proxy (Caddy, Traefik, nginx) in front of the container.

Backups

The relay database only contains encrypted data, so backing up relay.db is safe, but it is useless without your recovery key. Keep the key separately.
